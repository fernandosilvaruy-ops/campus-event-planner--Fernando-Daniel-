O Planejador de Eventos do IFConecta é uma aplicação em Python, desenvolvida em ambiente de console, que tem como objetivo facilitar o gerenciamento de eventos do IFB. O sistema permitirá cadastrar e visualizar eventos, filtrá-los por categoria ou data, registrar a participação dos usuários e gerar relatórios simples. O projeto será desenvolvido em equipe, com os integrantes trabalhando em módulos separados e, posteriormente, integrando suas implementações por meio do GitHub e de *pull requests*.
o seu modo de ultilização é através de um menu, no qual é mostrado as opções para que o usuário possa interagir com o planner de evento.
